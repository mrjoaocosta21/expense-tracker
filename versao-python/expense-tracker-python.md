# Expense Tracker Python
    A simple command-line Expense Tracker to add, view, update and delete your expenses.

* OVERVIEW
    This project helps users track their daily expenses. It allows you to add expenses with a category, amount and description, view all expenses, see summary by category, update and delete expenses. All data is stored in a CSV file so your expenses are saved permanently.

* FEATURES
    - Add new expense
    - View all expenses
    - View total expenses
    - View summary by category
    - Update an expense
    - Delete an expense
    - Data saved in CSV file
    - Easy to use in command line

* SKILLS USED
    - Functions
    - Lists & Dictionaries
    - File Handling (CSV)
    - Date & Time Module
    - Conditional Statements
    - Loops 

* TECHNOLOGIES
    - Python 3, csv, datetime modules

* HOW IT WORKS
    - Add expense with date, category, amount and description
    - Store expense in a CSV file
    - View all expenses in a table
    - See total expense
    - Update or delete any expense
    - Data persists even closing app

* RUN THE PROJECT
    - Install Python 3.x
    - Copy the code into a file named expense_tracker.py
    - Open terminal/command prompt
    - Run the program => python expense_tracker.py

* DATA STORAGE
    All expenses are stored in a CSV file (expenses.csv) in the following format:

        id |    date    |  Category  | Amount | Description
         1 | 2024-05-27 |    Food    | 250.00 | Lunch with friend
         2 | 2024-05-27 |   Travel   | 120.00 | Auto fare
         3 | 2024-05-28 |  Shopping  | 500.00 | New T-Shirt
